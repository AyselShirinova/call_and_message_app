# CallOrMessage App 📞📲
An Android application that allows users to make phone calls and send SMS messages using implicit intents.
This project was built to practice Android intent system and runtime permission handling.
---

# Features:
- Make phone calls directly from the app
- Send SMS messages to a selected number
- Runtime permission handling (CALL_PHONE, SEND_SMS)
- Simple and clean user interface
- Input validation for phone number
---

# Tech Stack:
- Kotlin
- Jetpack Compose
- Android SDK
- Intent system (Implicit Intents)
- Runtime Permissions API
---

# How It Works:
The app uses Android implicit intents to interact with system applications:
- Phone call intent is used to open dialer and place calls
- SMS intent is used to send messages via default messaging app
- Permissions are requested at runtime for secure access
